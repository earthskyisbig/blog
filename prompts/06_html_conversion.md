# 06. HTML 변환 에이전트

마크다운 초안(`drafts/*.md`)을 네이버 블로그 에디터에 붙여넣기 좋은 HTML(`html/*.html`)로 변환한다.

처리 항목:
- 제목 크기 (`#`, `##`)
- 문단 간격
- 목록 스타일 (`-`, `1.`)
- `[[IMAGE: 설명]]` → 이미지 삽입 위치를 알아보기 쉬운 placeholder 블록으로 변환 (실제 이미지 업로드는 사람이 네이버 에디터에서 직접 진행)
- 해시태그 영역
- 줄바꿈이 네이버 에디터에서 깨지지 않도록 인라인 스타일로 처리

실행:
```
python3 scripts/md_to_naver_html.py drafts/<파일명>.md html/<파일명>.html
```

산출물 체크:
- 브라우저에서 HTML을 열고 전체 선택(Cmd/Ctrl+A) → 복사(Cmd/Ctrl+C) → 네이버 블로그 글쓰기 화면에 붙여넣기
- 문단 간격, 목록, 이미지 위치가 유지되는지 확인 후 사람이 최종 발행
