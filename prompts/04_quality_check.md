# 04. 품질 검사 에이전트

초안이 나오면 이미지 단계로 넘어가기 전에 아래 항목을 코드/체크리스트로 검사한다. 사람이 "괜찮아 보인다"고 판단하기 전에, 아래 항목은 발견 즉시 실패 처리한다.

- [ ] 말투가 섞이지 않았는가 (문어체/구어체 혼용 없는가)
- [ ] 위키링크(`[[키워드]]`) 등 내부 노트 표기가 남아 있지 않은가 (단, `[[IMAGE: ...]]` 이미지 삽입 표시는 예외)
- [ ] 글자 수가 너무 짧지 않은가
- [ ] 제목과 본문 주제가 일치하는가
- [ ] 같은 문장 구조가 반복되지 않는가
- [ ] 경매 절차/권리관계 내용에 02 단계에서 확인된 근거가 실제로 반영됐는가
- [ ] 낙찰가율 등 시점성 수치를 근거 없이 단정하지 않았는가
- [ ] 이미지 삽입 위치(`[[IMAGE: ...]]`)가 커버 포함 4곳 있는가
- [ ] 해시태그가 붙어 있고 깨지지 않았는가
- [ ] 네이버에 붙여넣을 때 깨질 수 있는 마크다운 문법(표, 각주 등)이 남아 있지 않은가
