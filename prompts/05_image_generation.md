# 05. 이미지 생성 에이전트

본문의 `[[IMAGE: 설명]]` 위치마다 이미지 프롬프트를 만든다.

공통 규칙:
- 이미지 안에 글자를 넣지 않는다 (한글 텍스트 렌더링이 불안정하므로 제목은 후처리 단계에서 오버레이).
- 비율은 16:9로 통일한다.
- 로고/워터마크 금지.

경매 블로그 커버 이미지 프롬프트 예시:
```
네이버 블로그 커버 이미지.
주제: {블로그 제목}
장면: 법원 경매 입찰 서류를 작성하는 손, 또는 법원 게시판/서류 느낌의 사실적인 장면
스타일: 밝고 현실적인 사진 느낌, 과장 없는 신뢰감 있는 톤
비율: 16:9
금지: 이미지 안의 글자, 로고, 워터마크
```

섹션 이미지 프롬프트는 해당 섹션 주제(예: "권리분석 체크리스트", "입찰 절차")를 장면 묘사에 반영해서 커버와 톤을 맞춘다.
